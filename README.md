# Rover

Rover is the dashboard for building and running local lead-gen websites.

## Download

**Windows:** [Rover-Setup-2.8.30.exe](https://github.com/Rover-Application/download/releases/download/v2.8.31/Rover-Setup-2.8.30.exe)

Run the setup. Rover opens when the install finishes.

**Mac (Apple Silicon and Intel):** [Rover-Mac-2.8.31.zip](https://github.com/Rover-Application/download/releases/download/v2.8.31/Rover-Mac-2.8.31.zip)

Unzip the file. The first time you open Rover, right-click it and choose Open. If Git is missing, Rover tells you to install the Xcode command line tools.
