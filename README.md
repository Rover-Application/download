# Rover

Rover is the dashboard for building and running local lead-gen websites.

## Download

**Windows:** [Rover-Setup-2.8.34.exe](https://github.com/Rover-Application/download/releases/download/v2.8.34/Rover-Setup-2.8.34.exe)

Run the setup. Rover opens when the install finishes.

**Mac (Apple Silicon and Intel):** [Rover-Mac-2.8.34.zip](https://github.com/Rover-Application/download/releases/download/v2.8.34/Rover-Mac-2.8.34.zip)

Unzip the file. Drag Rover onto the Applications shortcut in that folder, then open Rover from Applications. The first time you open it, right-click Rover and choose Open. If Git is missing, Rover tells you to install the Xcode command line tools.
